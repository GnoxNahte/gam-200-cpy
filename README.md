# Team Project Starter

This repository is the starting point for your team's project.

- `.clang-format` / `.clang-tidy` — C/C++ style and lint rules for this project. Feel free to tweak them to your team's personal taste.
- `.gitignore` — ignores common build artifacts for C++/CMake, web, Android, and Python.

Replace this README with your own project documentation as work begins.
